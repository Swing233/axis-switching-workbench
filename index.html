📖 帮助看板 · 功能总览

🎬 播放与时间轴

  • 播放 / 暂停：空格；工具栏 ⏮ ◀ ▶ ▶ ⏭ 回到开头 / 逐帧 / 播放 / 结尾；可勾选循环
  • 逐帧步进：← / →（自动吸附帧边界）
  • 跳转播放头：点击或拖动标尺 / 轨道空白处（scrub 跟随），也可拖动波形
  • 🧲 帧吸附：播放头、关键帧拖动、粘贴全部自动对齐到帧边界（帧率见状态栏）
  • 🔍 缩放时间轴：按住 Alt 滚动滚轮（以鼠标位置为中心），或拖动「缩放」滑杆
  • 时长：工具栏直接修改总时长（秒）

◆ 关键帧编辑

  • 添加：「◇ 全部打关键帧」为所有轨道在播放头处打帧；双击轨道空白处为该轨道插帧
  • 自动打帧：直接拖动左侧参数面板滑杆或数值框，当前时间自动记录关键帧；按住 Shift 拖动滑杆进入精细调节（1/10 步进，滑杆青蓝高亮提示），可逐毫级微调参数
  • 参数范围手柄：新增——每个参数的滑杆是常用调节范围（手柄），数值框或按住拖拽可继续超出增减（安全边界内）；超出后滑杆贴边并变红高亮
  • 选中：单击菱形单选；⛶ 框选——在轨道空白处按住拖出矩形框选多帧（Shift 追加选择）
  • 移动：拖动菱形改时间；框选后拖动任一帧整组同步移动；按住 Shift 拖动强制吸附关键帧（跨轨道对齐，不受「🧲 吸附」开关影响）
  • 🧲 关键帧吸附：工具栏「吸附」开关（默认开启）——拖动关键帧时自动吸附到其他轨道上相近的关键帧，让不同轨道的帧对齐到同一时间列（阈值随时间轴缩放自适应，吸附命中时目标帧金色高亮）；开关关闭时按住 Shift 拖动可临时强制吸附
  • 编辑数值：双击菱形打开编辑器（时间 / 数值 / 插值）
  • 复制 / 剪切 / 粘贴：⌘C/⌃C、⌘X/⌃X、⌘V/⌃V（或 📋 按钮）——粘贴到播放头位置，保持各帧相对时间偏移，粘贴的帧默认线性插值
  • ∿ 批量插值：新增——选中（或框选）关键帧后，用工具栏「批量插值」下拉一键改为 平滑 / 线性 / 阶梯，一次可撤回
  • 删除：Delete / Backspace / X 批量删除选中帧；「🗑 清空所有关键帧」一键清空
  • 取消选择：Esc（再按关闭编辑器 / 帮助看板）

🎥 视角与画面

  • 视角切换：🎥 摄像机视角（按关键帧动画渲染）/ 🖐 自由视角（拖拽旋转 · 滚轮缩放 · 右键平移）——自由视角拖动只观察，不自动改动画；摆好机位后点「📌 同步视角」才写入关键帧并切回摄像机视角
  • 📌 同步视角：自由视角摆好机位后一键写入当前时间的关键帧并切回摄像机视角（不偏移视觉中心：仅旋转/缩放时视觉中心保持不变）
  • ◎ 视觉中心拾取：新增——顶栏「视觉中心」按钮进入拾取模式，在画面中点选场景物体（射流、孔板等；网格/扫描框/截面不算）即以该物体中心为视觉中心（写入当前时间的视觉中心关键帧；Esc 退出）；在「摄像机始终看向视觉中心」开启时画面立即对准该物体
  • 摄像机始终看向视觉中心：勾选时摄像机每帧朝向视觉中心（关键帧存 camX/Y/Z + tgtX/Y/Z）；取消勾选时朝向改由「旋转 X/Y/Z」关键帧控制，画面不跳变（当前朝向自动写入旋转关键帧），且自由视角的旋转中心随之变为相机前方视线点（不再以视觉中心为旋转中心）
  • 绕视觉中心旋转°：摄像机轨道组新增参数——相机位置绕视觉中心（tgt）绕 Y 轴旋转该角度（保持高度与朝向），0 即不旋转；配合「位置 X/Z」可实现以视觉中心为轴的环绕镜头（如 0°→90°→180°→270° 打环绕关键帧）
  • 📐 网格：全局坐标轴参考网格显示开关
  • 🔲 画幅框：显示最终导出视频的画面范围（虚线安全框）
  • 🎨 背景色：新增——顶栏「背景」下拉一键切换 深空蓝 / 纯黑 / 纯白 / 纯绿（抠像）等纯色背景，或右侧色板自定义任意颜色；背景实时生效并随导出视频一并输出（纯色抠像建议关闭 📐 网格）
  • 🎨 配色：新增——顶栏「配色」打开面板：可单独更改 流线笼/截面线/前端线/参考网格 的颜色与透明度，以及 液柱表面/截面填充/前端填充/扫描框 等平面的颜色与透明度；随工程自动保存
  • 🕳 孔板开关：新增——顶栏「孔板」按钮可显示/隐藏水流开始的孔板平台（随工程保存）
  • 面板高度：拖动时间线面板上边缘调整布局

🎙 音频与节奏

  • 导入口播：导入外部音频（mp3 / wav / ogg / m4a…），时间轴显示波形
  • 对齐：拖动播放头沿波形精确对齐关键帧节奏；点 🎙 标签可移除
  • 导出时可勾选「混入口播」合成进视频（实时录制模式）

💾 工程管理

  • 自动保存：所有修改实时保存到本地，刷新页面不丢失
  • 💾 保存工程：弹出保存窗口，可自定义文件名；Chrome/Edge 支持点「📁 浏览…」打开系统另存为，直接选择保存位置（其他浏览器保存到默认下载目录）。.json 工程文件可备份 / 分享
  • 📂 打开工程：从 .json 恢复全部关键帧与设置（也可直接把文件拖进页面）
  • 🗑 新建：清空当前内容恢复默认演示动画
  • 注意：音频不内嵌工程文件（仅波形数据），恢复后需重新导入音频

⬇ 导出动画

  • 格式：MP4（H.264 通用可预览）/ MOV（H.264 兼容容器）/ PNG 序列（ZIP 打包）
  • 文件名：新增——可自定义导出文件名；留空自动命名（有口播用音频名，否则用 模拟器名+日期）
  • 透明背景：新增——PNG 序列可选「透明背景」，导出帧背景透明（alpha 通道），便于 AE/剪辑后期合成或抠像
  • 精确帧率：无声导出采用 WebCodecs 精确编码，帧率严格等于所选值；混入口播时为实时录制
  • 导出范围即画幅框（🔲）所示画面

⌨️ 快捷键速查

  • 空格 播放 / 暂停　←→ 逐帧　Esc 取消选择 / 关闭面板
  • Delete / Backspace 删除选中关键帧
  • ⌘C/⌃C 复制　⌘X/⌃X 剪切　⌘V/⌃V 粘贴到播放头
  • ⌘Z/⌃Z 撤回　⌘⇧Z/⌃⇧Z/⌃Y 重做
  • Shift+框选 追加选择　Alt+滚轮 缩放时间轴　Shift+拖动菱形 吸附关键帧　Shift+拖动滑杆 精细调节
