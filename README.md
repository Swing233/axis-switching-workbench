# 射流轴交换 · Axis Switching — 关键帧动画工作台

水流通过非圆形小口（椭圆 / 矩形 / 方形）喷出后，因表面张力振荡形成"锁链状"水柱的物理模拟器，重构为**全参数关键帧动画工作台**。

基于原版 [axis-switching-simulator](https://github.com/) 的物理模型（`jetPhysics.ts` 移植为纯 JS），叠加 Three.js 可视化与时间轴动画编排能力。

## 功能特性

- **物理模型**：超椭圆（p=6）孔口、保面积收缩、3.5 次轴交换、粘性衰减、韦伯数/雷诺数驱动
- **关键帧动画**：10 条相机轨道 + 9 条参数轨道，Catmull-Rom 平滑 / 线性 / 阶梯插值
- **工程管理**：所有编辑自动保存到本地（刷新不丢），支持导出/导入 `.json` 工程文件（可备份/分享）、新建工程、拖拽文件恢复
- **时间轴编辑器**：拖拽 scrub 自动创建关键帧、菱形关键帧拖拽/编辑、播放头 scrub
- **多视角渲染**：玻璃材质喷射、热力图着色、扫描平面截面、24 线笼、带实时孔口的孔板
- **导出**：MP4 视频（H.264，全平台可预览）/ MOV 视频（H.264 兼容容器）/ PNG 序列（ZIP 打包，**可选透明背景 alpha 通道**，便于后期合成/抠像）。**无声导出采用 WebCodecs 精确编码，帧率严格等于所选值（60fps 就是 60fps）**

## 使用

```bash
# 方式一：直接打开（需本地静态服务器，因使用 ES Modules）
python3 -m http.server 8080 --directory .

# 方式二：双击 index.html（部分浏览器因 CORS 限制不可用，推荐方式一）
```

浏览器访问 `http://localhost:8080`。

## 操作指南

| 操作 | 说明 |
|---|---|
| 自动保存 | 所有关键帧/时长/设置修改后自动保存到本地，**刷新页面自动恢复**（也可手动点「💾 保存工程」下载备份） |
| 保存 / 打开工程 | 顶栏 💾 保存工程（下载 `.json` 文件）/ 📂 打开工程（也可直接把 `.json` 文件拖进页面） |
| 新建工程 | 顶栏 🗑 新建，清空当前内容恢复默认演示动画（建议先保存工程） |
| 点击时间轴 | 定位播放头（自动吸附到帧边界） |
| 拖拽参数值 | 自动创建关键帧（scrub） |
| 参数范围手柄 | 每个参数滑杆是常用调节范围（手柄），数值框或按住拖拽可**继续超出增减**（安全边界内，超出后滑杆贴边变红提示） |
| 配色 | 顶栏「🎨 配色」打开面板：可单独更改 流线笼/截面线/前端线/参考网格 的颜色与透明度，以及 液柱表面/截面填充/前端填充/扫描框 等平面的颜色与透明度；面板顶部嵌入**当前时间线画面预览**（150ms 实时刷新），每行右侧色块实时预览效果，可「↺ 重置配色」，修改可 ⌘Z 撤回；随工程自动保存 |
| 拖拽菱形关键帧 | 调整时间 / 数值（落点自动吸附到帧边界） |
| 缩放时间轴 | 拖动「缩放」滑杆，或按住 **Alt + 滚轮** 以鼠标位置为中心缩放（鼠标指向的时间保持不变） |
| 框选多帧 | 轨道空白处按住拖拽拉出矩形框，选中框内所有关键帧（Shift 追加选择）；拖动任一选中帧整组同步移动，Delete 批量删除，Esc 取消 |
| 复制 / 剪切 / 粘贴 | ⌘C / ⌘X / ⌘V（Ctrl 同）：把选中的一组关键帧（支持框选批量）复制或剪切，粘贴到当前播放头位置——保持各帧相对时间偏移，粘贴后自动选中可立即整组拖动；**粘贴的帧默认线性插值**；同位置重复粘贴覆盖不堆积；也可用工具栏「📋 粘贴关键帧」按钮 |
| 批量改插值 | 选中（或框选）关键帧后，用工具栏「∿ 批量插值」下拉一键改为 平滑 / 线性 / 阶梯（保持），一次可撤回 |
| 背景色 | 顶栏「🎨 背景」下拉一键切换 深空蓝（默认）/ 纯黑 / 纯白 / 纯绿（抠像）等纯色背景，或用右侧色板自定义任意颜色——预览实时生效，并随导出视频一并输出（绿幕抠像可直接后期合成；纯色背景建议关闭 📐 网格） |
| 孔板开关 | 顶栏「🕳 孔板」可显示/隐藏水流开始的孔板平台（随工程自动保存） |
| 帮助看板 | 顶栏「❓ 帮助」打开功能总览与快捷键速查（Esc / ✕ / 点遮罩关闭） |
| 双击菱形 | 编辑数值 |
| 播放 / 暂停 | 空格 或 播放按钮 |
| 撤回 / 重做 | ⌘Z / Ctrl+Z 撤回，⌘⇧Z / Ctrl+Shift+Z 或 Ctrl+Y 重做（或工具栏 ↩ 撤回 / ↪ 重做按钮）；支持全部关键帧修改操作 |
| 自由视角 → 📌 同步视角 | 自由视角摆好机位（旋转/缩放/右键平移）后点击，把当前视口机位写入播放头时间的关键帧；取消"看向视觉中心"时还会写入旋转角 |
| 导出 | 顶部工具栏 → 导出动画（MP4 H.264 / MOV H.264 兼容容器 / PNG 序列；PNG 序列可选「透明背景」输出 alpha 通道；无声导出为 WebCodecs 精确帧率编码，导出的视频可直接预览） |
| 导出命名 | 导出面板「文件名」可自定义；留空自动命名（有口播用音频名，否则 模拟器名+日期） |

## 技术栈

- Three.js r160（本地 vendored，无需 npm）
- 纯 vanilla JS 关键帧引擎（Catmull-Rom / 线性 / 阶梯）
- JSZip（PNG 序列导出）+ WebCodecs VideoEncoder（MP4 H.264 / WebM VP9 精确帧率编码，mp4-muxer/webm-muxer 封装）+ MediaRecorder（口播混音实时录制、WebCodecs 不可用时的回退）
